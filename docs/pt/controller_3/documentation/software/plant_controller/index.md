# plant_controller

The core of the Plant Controller is the python application plant_controller.

This application both serves the Web API, handles communication with the connected InfluxDB instance, tales measurements with the connected sensors, and waters the plants with the connected pumps.

See the documentation on the [CLI](./cli.md) if you want to run the program.

See the documentation on the [Source Code](../../../../../api/plant_controller/) if you want to extend the program.

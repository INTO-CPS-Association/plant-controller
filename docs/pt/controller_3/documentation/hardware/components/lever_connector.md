# Lever connector
![Image of a lever connector](lever_connector.jpg)

To connect the Plant Controllers different wires it is advised to use 
connectors instead of soldering. This is to allow easy disassembly, and to
ensure that all connections made are solid.

The type of connector does not matter, so long
as it is suitable for the wire thickness, and the number of connections in the
connector matches the number of wires that need to meet.

In the basic setup detailed in the [quick start guide](../../../setup/quick_start.md)
most of these connections are between two or three sets of two wires. To make
assembly simple (and allow for future extensions), we've used the same type of 
connector everywhere, which can be seen in the picture above.

This type of connector goes by many names, but should be sourceable by 
searching for "2 in 4 out lever connector" on Amazon or AliExpress.

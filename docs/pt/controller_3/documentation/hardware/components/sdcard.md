# Micro SD card
The [Raspberry Pi 5](rpi5.md) needs persistent storage to hold the software necessary for the Plant Controller. It is recommended to buy an SD card with at least 128 GB space, to allow for both the raspberry pi's operating system, the Plant Controller software, and the sensor data that the Plant Controller will accumulate during normal operation.

## Suppliers
Micro SD cards should be readily available in local consumer electronics stores and online.
